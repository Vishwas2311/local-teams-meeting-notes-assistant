# Privacy and consent

Use this program only for meetings you are authorized to capture and after satisfying participant
consent, employment policy, contract, and applicable law. Its visible console indicator must remain
on screen; do not modify it for covert use.

Raw audio and Whisper processing remain local. Only transcript text is sent to the configured Azure
OpenAI endpoint. There is no Teams bypass, Graph API, analytics, telemetry, or public API fallback.
Meeting data is never deleted automatically. Use the explicit cleanup command when appropriate.
